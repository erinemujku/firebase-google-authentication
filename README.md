#  Firebase Google Authentication App

This project is a simple authentication system built using **Firebase Authentication** and **React (or Expo)**.  
It allows users to register and log in using **Email/Password** or **Google Sign-In**.

##  Features

-  **Email and Password Authentication** – users can create an account and log in securely.  
-  **Google Sign-In** – users can log in using their Google account.  
-  **Responsive UI** – clean and minimal design for both web and mobile.  
-  **Firebase Integration** – handles user sessions and authentication with Firebase SDK.

##  Technologies Used

- **React / React Native / Expo**  
- **Firebase Authentication**  
- **JavaScript (ES6+)**  
- **React Navigation**  
- **Expo Google Auth / Firebase SDK**
